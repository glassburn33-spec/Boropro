# BoroPro Review Response - Quick Guide

## Quick Response Templates by Rating

### 5-Star Reviews ⭐⭐⭐⭐⭐

**Quick Response:**
```
Thank you for the 5-star review! We're thrilled BoroPro is helping with your glassblowing work. Your feedback motivates us to keep improving. Keep creating amazing glass!
```

**With Feature Mention:**
```
We're so glad you love the [calculator/kiln logging/glass science reference]! That's exactly what we designed it for. Thank you for the feedback—it helps us prioritize future improvements.
```

## Key Elements for Every Response

✓ **Thank you** - Always start with gratitude
✓ **Acknowledgment** - Reference specific points from the review
✓ **Action** - Offer a solution or next step
✓ **Contact** - Provide support email: support@manus.im
✓ **Tone** - Professional, empathetic, solution-focused

## Common Review Scenarios

### Scenario 1: "Love the calculator!"
```
We're so glad you love the calculator! That's exactly what we designed it for. Thank you for the feedback—it helps us prioritize future improvements.
```

### Scenario 2: "Offline mode saved my studio!"
```
We're happy the offline support is working well for you! That was a key priority when we built BoroPro. Thank you for recognizing that effort. Keep us posted on your work!
```

### Scenario 3: "Wish it had [feature]"
```
Thank you for the suggestion! [Feature] is a great idea. Please email support@manus.im with more details—we love hearing from our users and consider all feedback for future development.
```

### Scenario 4: "App crashed on my phone"
```
We're sorry you experienced a crash. Please contact support@manus.im with details about your device and what you were doing when it happened. We'll work to resolve this quickly.
```

### Scenario 5: "Calculations seem off"
```
We take accuracy very seriously. If you're seeing unexpected results, please contact support@manus.im with details about your inputs and results. We want to ensure our calculations are always precise.
```

### Scenario 6: "Not what I expected"
```
We're sorry if BoroPro wasn't what you expected. Please contact support@manus.im to discuss your needs. We may be able to help clarify what the app does or suggest how to use it better.
```

### Scenario 7: "Great update!"
```
Thank you for trying the latest update! We appreciate your feedback. Please let us know what you think at support@manus.im—your input helps us continue improving BoroPro.
```

### Scenario 8: "Recommended to my studio"
```
Thank you so much for recommending BoroPro! Word of mouth from satisfied users is the best compliment we can receive. We appreciate your support and look forward to helping more glassblowers.
```

## Response Checklist

Before posting a response, verify:

- [ ] Thank the user
- [ ] Address specific points from their review
- [ ] Use appropriate tone for the rating
- [ ] Offer a solution or next step
- [ ] Include support contact information
- [ ] Keep response concise (100-300 chars for iOS, up to 500 for Android)
- [ ] Check spelling and grammar
- [ ] Avoid defensive language
- [ ] Show genuine appreciation
- [ ] Provide value in the response

---

## Do's & Don'ts

### Do's ✓
- Thank users for feedback
- Be professional and courteous
- Address specific concerns
- Offer solutions
- Provide contact information
- Keep responses concise
- Show appreciation
- Take criticism seriously

### Don'ts ✗
- Be defensive
- Make excuses
- Ignore negative feedback
- Use generic responses
- Be sarcastic
- Argue with users
- Promise features you can't deliver
- Share personal information

## Monitoring Tips

1. **Check reviews daily** for the first week after launch
2. **Check 2-3 times per week** normally
3. **Respond to all reviews** when possible
4. **Track common themes** for product improvements
5. **Follow up** if user contacts support
6. **Ask for review updates** after issues are resolved
